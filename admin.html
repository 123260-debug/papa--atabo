はじめての方へ

この管理ページで、サイトの中身をすべて書き換えられます。最初に「接続」だけ済ませれば、あとは各タブで編集して、画面の下の「公開する」を押すだけです。

1

鍵(アクセストークン)を作る

  1. github.com/settings/personal-access-tokens/new を開きます
  2. 「Token name」に admin、「Expiration」は「90 days」を選びます
  3. 「Repository access」は「Only select repositories」にして、サイトのリポジトリだけを選びます
  4. 「Permissions」→「Repository permissions」→「Contents」を「Read and write」にします
  5. 一番下の「Generate token」を押して、github_pat_… をすべてコピーします(この画面を閉じると二度と見られません)
鍵は他の人に見せないでください。期限が切れたら、同じ手順で作り直せば大丈夫です。
2

この管理ページに接続する

  1. 上の「② 接続設定」を開き、GitHubのユーザー名、リポジトリ名、鍵を入れます
  2. 「接続テスト」を押して、上のバッジが緑の「接続OK」になれば成功です
3

編集して、公開する

  1. 下の表のタブで、書き換えたい場所を開きます
  2. 文章や写真を直します(英語の欄は、空でもかまいません。空のときは、英語表示でも日本語が出ます)
  3. 画面の一番下の「公開する」を押します。1〜3分で、サイトに反映されます
「公開する」は、いま開いているタブの内容だけを公開します。タブを変えるときは、先に「公開する」を押してください。

どのタブで何を直せる?

  • ③ 記事 … お知らせ(ニュース)の追加・編集・削除。写真と英語も付けられます
  • ④ 動画 … 動画の追加・削除・並べ替え、タイトル、再生時間、再生回数、あらすじ、サムネイル。動画IDを入れるだけで新しい動画も足せます
  • ⑤ 数字 … 登録者数・動画数・総再生数と、数字の日付(手入力です)
  • ⑥ BIO … プロフィールの文章と年表
  • ⑦ キャスト … 名前と写真
  • ⑧ チャンネル … 2つのチャンネルの名前・説明・リンク。チャンネルの追加もできます
  • ⑨ FAQ … よくある質問の追加・編集・削除・並べ替え
  • ⑩ 文言 … 上のどこにも入らない、サイト内のすべての文字(メニュー、見出し、ボタン、フッターなど)
  • ⑪ 全体 … トップの大きな写真、YouTubeへのリンク

YouTubeの数字は自動で変わりますか?

自動では変わりません。YouTubeの数字を自動で取るには、APIキーという仕組みが必要で、使わない方針にしました。代わりに、「⑤ 数字」で、登録者数などを書き換えます。30秒で終わります。

困ったとき

「HTTP 401」と出る

鍵が間違っているか、期限切れです。手順1で新しい鍵を作って、貼り付け直してください。

「HTTP 403」「HTTP 404」と出る

鍵の権限が足りないか、リポジトリが選ばれていません。手順1の「Repository access」と「Contents: Read and write」を確認してください。ユーザー名・リポジトリ名のつづり違いもよくある原因です。

公開したのにサイトが変わらない

反映まで1〜3分かかります。時間をおいて、ブラウザを再読み込み(スマホは更新)してください。

「公開できませんでした: … does not match」と出る

他の場所でも更新した場合に起きます。「② 接続設定」で「接続テスト」を押して、最新の内容を読み込み直してから、もう一度直して公開してください。

写真が入らない

先に接続テストを成功させてください。写真は自動で小さく整えられ、GitHubの images フォルダに保存されます。

直したのに元に戻ってしまう

「公開する」を押さずにページを閉じた可能性があります。変更があるとき、上に黄色の「未公開の変更あり」が出ます。

鍵はどこに保存される?

このブラウザの中だけです。共用のパソコンでは、使い終わったら「② 接続設定」の「設定を消去」を押してください。

GitHubとの接続

入れた内容は、このブラウザの中にだけ保存されます。
